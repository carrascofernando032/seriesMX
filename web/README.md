Desde la raíz del repositorio, ejecutar `python web/build.py` con Python 3 y Pandoc. El programa genera web/portal.zip con index.html en la raíz, /proyecto/ con el README y sus figuras, y /buscador/ con el acceso a la beta. Para probar, ejecutar `python -m http.server 8000 --directory web/dist` y abrir http://localhost:8000. Para publicar, respaldar public_html, extraer allí el contenido del ZIP y revisar las tres rutas por HTTPS. Repetir la generación tras actualizar README.md. Cambiar la variable beta si Google asigna otra URL de despliegue.
